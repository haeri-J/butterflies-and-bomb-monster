# 🦋 Butterflies and Bomb Monsters 💣

OpenGL(GLUT)로 만든 3D 애니메이션입니다. 키보드로 나비를 움직이면 폭탄 몬스터가 나비를 쫄쫄 쫓아갑니다.

> 처음으로 끝까지 완성한 그래픽스 프로젝트입니다.

## 주요 기능

- **잔디 바닥**: 나비는 잔디 밖으로 나갈 수 없습니다 (x, z 좌표가 -7.5 ~ 7.5 범위로 제한됩니다).
- **나비의 날갯짓**: 몸통 하나와 **자식 노드인 날개 4개**로 이루어진 계층 구조입니다. `sin()` 함수로 날개를 위아래로 움직입니다.
- **폭탄 몬스터의 계층 모델링**: 동그란 몸통에 다음이 붙어 있습니다.
  - 위쪽: 원통형 심지 1개
  - 앞쪽: 눈 2개
  - 아래쪽: 원통형 다리 2개와 각 다리에 연결된 원통형 발 2개
- **키보드 조작**: 방향키(↑ ↓ ← →)로 나비를 움직입니다.
- **추적**: 폭탄 몬스터가 타이머 콜백으로 나비가 마지막으로 멈춘 위치까지 따라갑니다.
- **걷기 애니메이션**: 처음에는 다리가 멈춰 있다가, 키를 누르면 다리를 흔들며 걷기 시작합니다.

## 조작법

| 키 | 동작 |
|---|---|
| ↑ / ↓ | 나비를 앞 / 뒤로 이동 |
| ← / → | 나비를 왼쪽 / 오른쪽으로 이동 |

## 실행 방법

### Windows (Visual Studio)
1. 새 C++ 콘솔 프로젝트를 만들고 `main.cpp`를 추가합니다.
2. NuGet에서 `nupengl.core`를 설치합니다 (또는 freeglut을 직접 연결합니다).
3. 빌드하고 실행합니다.

### Linux
```bash
sudo apt install freeglut3-dev
g++ main.cpp -o main -lGL -lGLU -lglut
./main
```

## 사용 기술
- C++
- OpenGL / GLU / GLUT
- 계층적 모델링 (`glPushMatrix` / `glPopMatrix`)
- 타이머 콜백 기반 애니메이션

## 아쉬운 점
- 몬스터가 나비에 도착하면 다리도 멈추게 하고 싶었는데, 구현하지 못했습니다.
  원인은 `float` 좌표를 `==`로 비교한 것이었습니다. `0.0025`씩 더하고 빼다 보면 오차가 쌓여서 값이 정확히 같아지지 않습니다.
  → 오차 범위 안에 들어오면 같은 것으로 보는 방식(`fabs(BX - x) < 0.0025`)으로 고칠 수 있습니다.
